# Install (Windows 10/11) — Best-effort / Not the main target

Windows can work, but SDR drivers + Soapy stacks can be finicky. This guide is **best-effort**.
If you get stuck, open an issue or message the maintainer.

---

## 1) Install HackRF tools

Install HackRF tools so `hackrf_sweep.exe` and `hackrf_info.exe` work.

Verify in PowerShell:

```powershell
hackrf_info
hackrf_sweep -h
```

If HackRF isn’t detected, use Zadig to install the WinUSB driver for HackRF.

---

## 2) Install Python

Install Python 3.x from python.org and ensure **“Add Python to PATH”** is checked.

Verify:

```powershell
python --version
pip --version
```

---

## 3) Get the repo

Clone or download the repo. If you download a ZIP, extract it somewhere like:

`C:\Users\<you>\Projects\Watchdog`

---

## 4) Create a venv + install requirements

In PowerShell:

```powershell
cd path\to\Watchdog
python -m venv .venv
.\.venv\Scripts\activate
python -m pip install -U pip
pip install -r requirements-windows.txt
python main.py
```

---

## Notes

- If HackRF isn’t detected, use Zadig to install the correct **WinUSB** driver for HackRF.
- If you are using bladeRF/Soapy features on Windows, you may need a working SoapySDR environment (often easiest via PothosSDR) plus bladeRF drivers/tools.
