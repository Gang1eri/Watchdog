# Install (Raspberry Pi OS Bookworm / DragonOS Pi64)

These steps are tested on Debian-based Raspberry Pi images (Raspberry Pi OS Bookworm 64-bit, DragonOS Pi64, etc.).

**Why apt + venv?**
- We install **PyQt5 via `apt`** (most reliable on ARM / Debian).
- We use a Python **venv** for pip-only dependencies.

---

## 1) Update OS + install system packages (APT)

```bash
sudo apt update
sudo apt full-upgrade -y
sudo reboot
```

After reboot:

```bash
sudo apt update
sudo apt install -y   git   hackrf   python3 python3-venv python3-pip   python3-pyqt5 python3-pyqt5.qtmultimedia   python3-pyqtgraph
```

Sanity check:

```bash
hackrf_info
hackrf_sweep -h | head -n 5
python3 -c "from PyQt5 import QtWidgets; print('PyQt5 OK')"
python3 -c "from PyQt5.QtMultimedia import QSoundEffect; print('QtMultimedia OK')"
```

---

## 2) Clone Watchdog

If the repo is private, `git clone` will prompt for credentials. Use a GitHub **Personal Access Token** as the password.

```bash
cd ~
git clone https://github.com/Gang1eri/Watchdog.git
cd Watchdog
```

---

## 3) Create a venv (IMPORTANT on Debian/DragonOS)

Because PyQt5 is installed via `apt`, your venv must include system site-packages.
Otherwise you may see: `ModuleNotFoundError: No module named 'PyQt5'`.

```bash
python3 -m venv .venv --system-site-packages
source .venv/bin/activate
python -m pip install -U pip
```

Install pip-only deps:

```bash
pip install -r requirements-pi.txt
```

---

## 4) Run

```bash
python3 main.py
```

---

## 5) Desktop shortcut (optional)

This repo includes Linux launcher assets under `packaging/linux/`.

Depending on what you’ve renamed so far, you may see either:
- `packaging/linux/Watchdog.desktop` **or**
- `packaging/linux/HackRF-Watchdog.desktop` (legacy filename)

Open the `.desktop` file and edit `Exec=` and `Path=` to match your username and install folder.
Example (adjust to your path):

```ini
Exec=/home/dragon/Watchdog/packaging/linux/run_watchdog.sh
Path=/home/dragon/Watchdog
```

Then copy it to your applications folder:

```bash
mkdir -p ~/.local/share/applications
cp packaging/linux/*.desktop ~/.local/share/applications/
chmod +x ~/.local/share/applications/*.desktop
```

## Troubleshooting

### PyQt5 import error inside venv
If you see `No module named 'PyQt5'`, recreate the venv with system site packages:

```bash
cd ~/Watchdog
deactivate 2>/dev/null || true
rm -rf .venv
python3 -m venv .venv --system-site-packages
source .venv/bin/activate
pip install -r requirements-pi.txt
python3 main.py
```

### HackRF permission issues
If `hackrf_info` only works with `sudo`, you may need udev rules for HackRF access.
